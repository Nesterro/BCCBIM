# BIMBCC PlugIn for Autodesk Revit 2024

Линейка плагинов для Autodesk Revit на C# в минималистичном красно-белом стиле. Первая реализованная функция — **Экспорт листов в PDF** (версия 2024).

---

## Возможности функции «Экспорт в PDF» (v5.1)

1. **Исправление бага с кавычками в шрифте GOST Common:**
   - Плагин использует Revit Print API (`PrintManager`) через виртуальный PDF-принтер, что позволяет печатать кавычки-ёлочки `«` и `»` без искажений (они больше не превращаются в дроби `½` и `¼` в векторном PDF).
2. **Интерактивный интерфейс (WPF):**
   - Удобный поиск листов по шифру и названию.
   - Поддержка выбора стандартных наборов листов Revit из выпадающего списка.
   - Выбор установленного в системе PDF-принтера с автоопределением по слову "PDF".
   - Настройка параметров печати: формат бумаги (Авто, A0-A4), ориентация, цветопередача, масштаб и тип обработки графики (векторная/растровая).
3. **Бесшовная работа:**
   - Информативный прогресс-бар процесса печати, не блокирующий интерфейс Revit.
   - Автоматическая очистка старых версий файлов в папке назначения (предотвращение ошибок перезаписи).
   - Финальное диалоговое окно с предложением открыть папку с результатами в Проводнике Windows.
4. **Фирменный дизайн:**
   - Строгая красно-белая палитра интерфейса.
   - Кастомная иконка на ленте Revit.

## Структура проекта

* `BCCPlugIn.csproj` — файл проекта SDK-style, нацеленный на .NET Framework 4.8. Использованы современные NuGet-пакеты Nice3point.Revit.Api.
* `BCCPlugIn.addin` — файл манифеста для регистрации плагина в Revit.
* `App.cs` — класс приложения (`IExternalApplication`), создающий вкладку **BIMBCC**, панель и кнопку на ленте. Оптимизирован для безопасной загрузки встроенных изображений.
* `ExportPdfCommand.cs` — класс команды (`IExternalCommand`), выполняющий логику сбора листов, настройки параметров печати `PrintManager` и запуска процесса.
* `ExportWindow.xaml` / `ExportWindow.xaml.cs` — основное окно настроек экспорта.
* `ProgressWindow.xaml` / `ProgressWindow.xaml.cs` — окно индикатора выполнения.
* `Resources/pdf_export_icon.png` — встроенный ресурс иконки кнопки (32x32).

## Сборка проекта

Для сборки проекта вам потребуется установленный .NET SDK (поддерживающий .NET Framework 4.8).

1. Откройте консоль (PowerShell / CMD) в папке проекта.
2. Выполните команду сборки:
   ```bash
   dotnet build -c Release
   ```
3. Скомпилированные файлы (`BCCPlugIn.dll`) будут находиться в папке `bin/Release/`.

---

## Установка

1. Скопируйте файл манифеста `BCCPlugIn.addin` из корня проекта.
2. Скопируйте файл сборки `BCCPlugIn.dll` из папки `bin/Release/`.
3. Поместите оба файла в каталог автозагрузки плагинов Revit 2024:
   ```text
   %APPDATA%\Autodesk\Revit\Addins\2024\
   ```
4. Запустите Revit. На вкладке **BIMBCC** появится кнопка экспорта.

## Совет по бесшумной печати (без окон сохранения)
Если вы хотите выполнять печать в один клик без постоянного подтверждения путей сохранения в Windows:
1. Выберите в качестве принтера в плагине **PDF24** (или **PDFCreator**).
2. Зайдите в настройки самого принтера в Windows.
3. Включите опцию **«Автосохранение»** (Auto-save) и укажите папку по умолчанию.
